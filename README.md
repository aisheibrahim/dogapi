
# 🐶 Dog Image Finder App

Users can search by breed or view random dog images with the click of a button.

## 🚀 Features

* Search for dog images by breed
* Fetch random dog pictures
* Clean, responsive user interface
* Built using HTML, CSS, and JavaScript

## 🧰 Technologies Used

* JavaScript (Fetch API)
* HTML/CSS
* Dog CEO API ([https://dog.ceo/dog-api/](https://dog.ceo/dog-api/))

## 📦 Setup Instructions

1. Clone the repository
2. Open `index.html` in your browser
3. Start searching for dog images!
